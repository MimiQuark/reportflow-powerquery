Excel + Power Query Automated Operating Report

把 4 张源表自动清洗、关联、计算、汇总为可刷新经营看板。自动化核心不是“没有人工”，而是把重复处理步骤固化为可复用、可验证的数据流程。

自动化处理链路

1. 源数据销售 / 商品 / 退货 / 目标
2. 清洗类型转换与异常过滤
3. 关联商品与订单数据合并
4. 计算销售额、成本、毛利、完成率
5. 输出看板 / 透视表 / 异常表

一键刷新

6 条查询全部嵌入工作簿。点击“数据 → 全部刷新”后，Excel 会按依赖顺序自动重新执行：qry_fact_sales 生成事实表，月度、品类、区域、退货和质量查询再基于事实表更新。无需手工复制、合并或重新计算指标。

体现自动化的 6 条查询

查询自动完成的工作
qry_fact_sales清洗销售数据、关联商品并计算销售额、成本、毛利
qry_monthly_kpi按月汇总销售、订单、目标、完成率和环比
qry_category_kpi自动计算品类销售额、毛利和排名
qry_region_kpi汇总区域销售、客户数和目标完成率
qry_return_summary自动汇总退货原因、金额和退货率
qry_quality_issues识别无效商品、异常数量和折扣越界

验证与交付

自动化不是静态截图：Power Query 已通过 Mashup OLEDB 实际刷新测试，6 条查询均返回有效的行列结果。工作簿同时包含数据透视表、经营看板、字段口径、异常清单和版本记录。
